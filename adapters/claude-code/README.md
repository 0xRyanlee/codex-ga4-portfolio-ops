# Claude Code adapter

Claude Code supports the Agent Skills layout. Copy or install the package as:

```text
.claude/skills/codex-ga4-portfolio-ops/SKILL.md
```

Keep the sibling `references/` and `scripts/` directories available relative to the skill root, or copy the complete package into the skill directory. Use the Claude Code browser/tool surface available in the current environment for GA4 Admin actions; this repo does not assume the Codex `sky` runtime exists.

Official references: [Claude Code skills](https://code.claude.com/docs/en/slash-commands) · [Claude Agent Skills](https://support.claude.com/en/articles/12512176-what-are-skills)

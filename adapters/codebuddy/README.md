# CodeBuddy adapter

CodeBuddy exposes skills under `.codebuddy/skills/` and can package skills through plugins. Copy the portable `SKILL.md`, `references/`, and `scripts/` into the project or plugin layout supported by the installed CodeBuddy version.

This adapter provides instructions, not permissions. The agent still needs an approved repository, browser, Google Analytics account, or API credential to perform the corresponding action. If those surfaces are unavailable, produce a plan and QA handoff.

Official references: [CodeBuddy overview](https://www.codebuddy.ai/docs/ide/User-guide/Overview) · [CodeBuddy plugins](https://www.codebuddy.ai/docs/cli/plugins-reference)

# OpenClaw adapter

OpenClaw discovers skills from workspace, project-agent, personal, managed, or extra directories. Install this package in the configured skill root and use an agent allowlist to expose it only to the agent that needs GA4 operations.

Before enabling:

- read the full `SKILL.md` and scripts;
- run the validator in a sandbox or review environment;
- grant browser/API credentials only for the approved account and task;
- keep `api_secret`, tokens, cookies, and PII out of skill files and logs;
- require human approval before property deletion, linking, data deletion, or external communication.

Official reference: [OpenClaw Skills](https://docs.openclaw.ai/skills)

## AEO answer patterns

Use explicit question headings and answer in the first sentence:

- What is this? A portable GA4 measurement and QA workflow for websites, WebApps, native apps, and agent runtimes.
- Can GA4 track macOS and Android apps? Yes; use Firebase app streams and the platform SDK rather than a Web stream.
- What is the difference between `cta_click` and `generate_lead`? The former is intent; the latter is a confirmed lead outcome.
- Can one skill run in every AI tool? The core `SKILL.md` is portable where Agent Skills is supported; other tools need a rules or skills adapter.
- Does this use stealth browser automation? No; it uses visible, auditable actions with state checks and bounded UI-settle waits.
